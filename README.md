# Project 2: Data Classification Using AI

## Objective

Build a basic classification model using a small dataset.

## Project Description

This project demonstrates the basic workflow of supervised learning by training a machine learning model to classify data into different categories.

## Dataset

The Iris dataset is used for this project.

The dataset contains measurements of Iris flowers and their corresponding species.

The three species are:

- Setosa
- Versicolor
- Virginica

## Steps Performed

1. Loaded and understood the Iris dataset
2. Split the dataset into training and testing sets
3. Applied feature scaling using StandardScaler
4. Implemented the K-Nearest Neighbors (KNN) classification algorithm
5. Trained the classification model
6. Generated predictions on the test data
7. Evaluated the model performance

## Technologies Used

- Python
- Scikit-learn
- Matplotlib
- Pytest

## Model Performance

- Accuracy: 93.33%
- Precision: 94.44%
- Recall: 93.33%
- F1 Score: 93.27%

Automated testing was performed using Pytest.
